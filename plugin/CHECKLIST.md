# Ручная проверка в STE Slicer

Автотесты работают на заглушках: `bridge_fake.py` и заглушки Uranium. Здесь — то, что видно только в
настоящем STE Slicer. Проверка занимает около 30 минут. Нужны три модели: плоская деталь
(кронштейн), тело вращения с каналом (колесо, втулка) и любая третья. Для пунктов с LLM нужен ключ.

Отметьте результат: ✅ — как ожидалось, ❌ — запишите, что увидели, и приложите журнал `steslicer.log`
(Help → Show Configuration Folder).

## 1. Запуск

| # | Действие | Ожидаемый результат | ✅/❌ |
|---|---|---|---|
| 1.1 | Установить плагин по `README.md`, перезапустить STE Slicer | В меню расширений есть «AI Assistant», окон с ошибками нет | |
| 1.2 | «AI Assistant» → «Открыть чат» | Браузер открывает чат, внизу слева «STE Slicer подключён» | |
| 1.3 | Настройки → LLM: адрес, модель, ключ → «Проверить» | «Ответ», «Инструменты»; «Изображения» — если модель видит фото | |

## 2. Деталь от модели до файла

| # | Действие | Ожидаемый результат | ✅/❌ |
|---|---|---|---|
| 2.1 | Перетащить кронштейн в чат, «Кронштейн, 2 штуки» | Модель появилась на столе, карточка модели с габаритами, затем вопросы | |
| 2.2 | Ответить на вопросы, «Подтвердить и нарезать» | Нарезка с прогрессом, паспорт с временем, массой и ценой. Время совпадает с панелью STE Slicer | |
| 2.3 | Паспорт → «Заполнение» → 40 → «Применить» | В STE Slicer «Плотность заполнения» = 40 %, деталь перенарезана, в ленте «Было → стало», в паспорте источник «вы» | |
| 2.4 | «Отменить» в карточке «Было → стало» | В STE Slicer снова прежнее значение, карточка «Отменено» | |
| 2.5 | «Все настройки STE Slicer», найти «поток» | Список с русскими подписями, значение меняется и видно в STE Slicer | |
| 2.6 | «Вернуть исходные» | Правки пользователя сняты, в STE Slicer значения профиля | |
| 2.7 | «Сохранить проект 3MF», затем «Экспорт G-code» | Файлы в папке из настроек, запись в картотеке. 3MF открывается в STE Slicer с теми же настройками | |

## 3. Несколько деталей — одна сцена

| # | Действие | Ожидаемый результат | ✅/❌ |
|---|---|---|---|
| 3.1 | «Новая деталь», загрузить колесо, довести до нарезки | Кронштейн убран со стола, колесо в 5D (если канал по оси) | |
| 3.2 | Вернуться к кронштейну, написать «сделай дешевле» | В ходе работы шаг «Вернул деталь в сцену», на столе **кронштейн** в прежнем положении, 2 копии, его материал и настройки | |
| 3.3 | Вернуться к колесу, «Нарезать заново» | На столе колесо, режим 5D, база как в паспорте | |
| 3.4 | Повторить 3.2–3.3 три раза подряд | Ни разу не загрузилась модель другой детали | |
| 3.5 | Повернуть кронштейн руками в окне STE Slicer, затем написать в чат | **Известное ограничение:** плагин не замечает ручной поворот. Запишите, что произошло | |

## 4. Разбор по фото и опыт

| # | Действие | Ожидаемый результат | ✅/❌ |
|---|---|---|---|
| 4.1 | На сохранённом кронштейне «Разобрать печать по фото», приложить фото | Модель для фото называет дефекты или задаёт вопрос; без LLM — выбор вручную | |
| 4.2 | Отметить «Переэкструзия: наплывы» и «Слоновья нога» | Исправления: поток −5 %, расширение первого слоя −0,2 мм (в 3D), стол холоднее | |
| 4.3 | «Применить исправления» | Значения в STE Slicer, перенарезка; в картотеке у записи «Были проблемы» и блок «Запомнил для следующих деталей» | |
| 4.4 | Новая деталь из того же материала в 3D | В плане строка «Поток» с источником «опыт», в чате «Учёл опыт прошлых печатей…» | |
| 4.5 | Та же модель, но 5D или другой материал | Опыт не применяется | |
